# Pankhil Gawade — Personal Website

Personal academic portfolio for **Pankhil Gawade**, Doctoral Researcher at Helmholtz Munich & TUM (ELLIS · MCML · ELIZA), specializing in topology-aware generative AI, drug discovery, and antimicrobial peptide design.

Live site: **[https://pankhil07.github.io](https://pankhil07.github.io)**

- Tailwind CSS
- Deployed via GitHub Pages
